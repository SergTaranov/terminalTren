# terminalTren — тренажёр командной строки Linux

Интерактивная система обучения работе с терминалом Linux: два уровня сложности,
теория и практика со встроенным эмулятором shell. Написана на Go, работает на
Windows, Linux и macOS — настоящий Linux не требуется, все команды выполняются
в безопасной виртуальной файловой системе.

## Возможности

- **TUI-интерфейс** (bubbletea): главный экран с прогрессом, список уроков,
  прокручиваемая теория, практический терминал.
- **Виртуальный shell**: файловая система с правами доступа и владельцами,
  конвейеры `|`, перенаправления `> >> < 2>`, переменные окружения, `$()`,
  арифметика `$(( ))`, алиасы, глоббинг `* ? []`, bash-скрипты (if/for/while/
  функции).
- **79 команд**: ls, cd, cp, mv, find, grep, sort, uniq, cut, tr, tee, xargs,
  sed, awk, chmod, chown, sudo, tar, gzip, ps, kill, top, df, du, free, ping,
  curl, ss, systemctl, journalctl, crontab и другие. `man команда` — краткая
  справка на русском, `help` — список команд.
- **21 урок** (10 базовых + 11 продвинутых), в каждом — теория и 4–5 упражнений
  с автоматической проверкой.
- **Прогресс** сохраняется между запусками (`progress.json` в профиле
  пользователя).
- **Уроки — внешние JSON-файлы**: можно править и добавлять свои без пересборки.

## Сборка и запуск

Требуется Go 1.24+.

```
go build -o terminalTren .
./terminalTren
```

Программа ищет уроки в каталоге `lessons/` рядом с собой; другой путь можно
указать флагом:

```
./terminalTren -lessons /путь/к/lessons
```

## Управление

| Экран | Клавиши |
|---|---|
| Главное меню / список уроков | `↑/↓` выбор, `Enter` открыть, `q` выход |
| Урок | `1`/`Tab` теория, `2` практика |
| Теория | `↑/↓` прокрутка, `PgUp/PgDn`, `g`/`G` |
| Практика | `Enter` выполнить команду, `↑/↓` история |
| Практика | `F1` подсказка, `F2` показать решение, `F3` сбросить песочницу |
| Практика | `Ctrl+L` очистить вывод, `Esc` назад |

## Структура проекта

```
main.go                  точка входа
lessons/
  basic/                 базовый уровень (10 уроков)
  advanced/              продвинутый уровень (11 уроков)
internal/
  vshell/                виртуальный shell: VFS, лексер, конвейеры, команды
  curriculum/            модель урока и загрузчик JSON
  trainer/               сессия урока, проверка упражнений, прогресс
  ui/                    экраны TUI
```

## Свои уроки

Урок — JSON-файл в `lessons/basic/` или `lessons/advanced/` (файлы читаются
по алфавиту, поэтому префикс `01-`, `02-`, … задаёт порядок):

```json
{
  "id": "my-lesson",
  "title": "Мой урок",
  "level": "basic",
  "theory": [
    { "title": "Раздел", "body": "Текст с `кодом`, **жирным** и блоками ```" }
  ],
  "exercises": [
    {
      "id": "ex1",
      "task": "Создайте файл report.txt",
      "setup": {
        "cwd": "/home/user",
        "dirs":  [{ "path": "/home/user/docs" }],
        "files": [{ "path": "/home/user/notes.txt", "content": "заметки\n" }],
        "processes": [{ "pid": 1234, "cmd": "my-daemon", "cpu": 1.5 }],
        "units":     [{ "name": "my.service", "active": "active" }]
      },
      "checks": [
        { "type": "fs_exists", "path": "/home/user/report.txt" }
      ],
      "hints": ["Подсказка 1", "Подсказка 2"],
      "solution": "touch report.txt"
    }
  ]
}
```

### Типы проверок

| Тип | Значение | Что проверяет |
|---|---|---|
| `fs_exists` | `path` | путь существует |
| `fs_absent` | `path` | путь отсутствует |
| `fs_content_contains` | `path`, `value` | файл содержит подстроку |
| `fs_content_equals` | `path`, `value` | файл равен строке |
| `fs_perm` | `path`, `value` | права равны окталу (`644`) |
| `cmd_used` | `value` | введена команда по регулярному выражению |
| `output_contains` | `value` | вывод последней команды содержит строку |
| `output_not_contains` | `value` | вывод не содержит строку |
| `cwd_is` | `value` | текущий каталог равен пути |

`setup` необязателен; песочница пересоздаётся для каждого упражнения.

## Тесты

Юнит-тесты ядра shell и **автопроигрывание всех решений всех уроков**
(каждое упражнение решается эталонной командой и проверяется чекером):

```
go test ./...
```

Благодаря этому тесту контент уроков не может «протухнуть»: любое изменение
команд или проверок, ломающее решение, падает на CI/локально.
